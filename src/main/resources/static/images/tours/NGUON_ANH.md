# Nguồn ảnh tour (ảnh seed, đi kèm mã nguồn)

Toàn bộ 20 ảnh trong thư mục này lấy từ **Wikimedia Commons** — mọi ảnh trên Commons đều
mang giấy phép tự do (Creative Commons hoặc phạm vi công cộng), **cho phép dùng cả cho mục
đích thương mại**. Ảnh gốc được tải về, resize ngang ~1200px, nén JPEG chất lượng ~80,
mỗi file dưới 250 KB.

## Cách tải lại / cập nhật

Ảnh được tải bằng script Python dùng `urllib` + Wikimedia Commons API
(`action=query&list=search` rồi `action=query&prop=imageinfo`), lọc theo giấy phép tự do
(CC0 / Public domain / CC BY / CC BY-SA), ưu tiên ảnh tỉ lệ ngang và độ phân giải cao, sau đó
resize về bề ngang 1200px và nén JPEG bằng Pillow. Script không được lưu lại trong repo (chạy
một lần, mục đích duy nhất là tải ảnh) — muốn tải lại thì lặp lại đúng quy trình trên với từ
khoá tìm kiếm tương ứng ở cột "Tour" của bảng trên.
